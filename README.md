# Infotainer Mod

A customizable Minecraft Fabric Mod for version 26.2 that displays a HUD with real-time information.

## Features

- **Date & Time Display**: Shows current date and time in your HUD
- **Twitch Followers**: Display your Twitch channel's follower count (requires OAuth token)
- **Weather Information**: Shows real-time weather conditions in your current world
- **Fully Customizable**: Configure everything through the Mod Menu
- **Flexible HUD Positioning**: Place the HUD anywhere on your screen

## Installation

1. Install Fabric Loader 0.15.3+ for Minecraft 26.2
2. Install Fabric API 0.96.1+1.26.2+
3. Install Mod Menu 13.0.0+1.26.2+
4. Download the Infotainer mod jar and place it in your `mods` folder
5. Launch Minecraft

## Configuration

### Access Settings

Open the Mod Menu in the main menu and click on Infotainer settings.

### Available Settings

- **Show Date/Time**: Toggle date and time display
- **Show Twitch Followers**: Toggle Twitch follower count display
- **Show Weather**: Toggle weather information display
- **HUD X/Y Position**: Customize HUD position
- **Twitch Channel**: Enter your Twitch channel name
- **OAuth Token**: Enter your Twitch OAuth token
- **12/24 Hour Format**: Toggle time format

## Twitch Setup

To enable Twitch follower display:

1. Get your OAuth token from https://twitchtokengenerator.com/
2. Enter your channel name and OAuth token in the mod settings
3. Save and enjoy!

## Configuration File

Settings are saved to `config/infotainer.json`

## Requirements

- Minecraft 26.2
